# Robotic Muscle Therapy

An Astro + Tailwind CSS one-page landing site for RoboticMuscleTherapy.com, helping people research pain and Robotic Precision Therapy in Troy, Michigan and the surrounding Detroit area.

## Project goals

- Present a modern, accessible introduction to the clinic's clinician-guided robotic therapy.
- Help visitors explore sciatica, lower-back pain, herniated discs, and related pain topics.
- Direct visitors to https://rptclinic.com/contact for care inquiries.
- Use original content and link to RPT Clinic resources where helpful; avoid duplicating entire articles or promising medical outcomes.

## Planned stack

Astro, Tailwind CSS, and a static Cloudflare Pages deployment connected to this GitHub repository. Source files live here; Cloudflare builds and hosts the finished site.

## Status

The landing page is ready for the RoboticMuscleTherapy.com domain. Production analytics remain intentionally unset until deployment configuration is provided.
